# Product Brief: StockManagement

## エグゼクティブサマリー

StockManagement は、企業価値評価の基本理論を個人投資家が自分の手で実践できるオープンソースのWebアプリケーションである。

個人の中長期投資家が、堅実な株価決定理論と定性的な企業分析を組み合わせ、自信を持って投資判断を行えるようにすることを目的とする。現在、規律ある株価評価手法を実践する個人投資家は、四半期ごとに決算短信や有価証券報告書から財務データを手作業で転記するという、膨大な時間がかかりミスも起きやすいプロセスを強いられている。既存の無料ツールはスクリーニング機能は提供するが、理論に基づいた適正株価の算出はできない。有料ツールは、本来増やすべき投資リターンを食い潰してしまう。

StockManagement は、公式開示情報からの財務データ収集を段階的に自動化し、実証済みの株価評価理論に基づいて理論株価を算出し、AIによる定性分析を重ねることでこの課題を解決する。すべての計算ロジック・データ判定・前提条件を完全に開示する「透明性の原則」を設計思想の中核に据え、怪しい投資商材やブラックボックス型ツールの真逆を目指す。

## コアビジョン

### 課題

規律ある理論ベースの株式分析を実践する個人投資家は、苦痛な手作業のワークフローに直面している。四半期ごとに、数十社の決算資料から財務データ（売上高、営業利益、キャッシュフロー、有利子負債等）を転記しなければならない。勘定科目の表現は企業によって微妙に異なり（例：何が「有利子負債」に該当するかの判定）、正確なデータ抽出に時間がかかりミスも生じやすい。このボトルネックが、分析可能な企業数を制限し、抜け漏れや機会損失を招いている。

### 課題のインパクト

- **時間の浪費**: 決算シーズンが分析や意思決定ではなく、何週間ものデータ入力作業になる
- **カバレッジの限界**: 50社以上を手動で追跡することは現実的に不可能であり、機会を逃す
- **判断の難しさ**: 定性分析が統合されていないため、自信を持った売買判断に必要な全体像が見えない
- **感情的な脆弱性**: 体系的で理論に裏打ちされたフレームワークがすぐに参照できないと、市場ショック時にパニック売りしやすくなる
- **知識の障壁**: 一般の投資家は適切な株価評価ツールにアクセスできず、怪しい投資手法や商材ビジネスの餌食になりやすい

### 既存ソリューションの限界

- **無料スクリーニングツール**（バフェットコード、証券会社のスクリーナー等）: 時点データやフィルタリングは提供するが、理論に基づく適正株価の算出はできない。重要機能は有料版に制限されがち。計算の定義や根拠が不透明
- **有料分析プラットフォーム**: 向上させるべき投資リターンを購読料で食い潰す。年間10%のリターンを目指す個人投資家にとって、定期課金は正当化しづらい
- **スプレッドシート**: 完全な自由度とカスタマイズ性はあるが、データ入力は完全手動で、自動化もフィルタリングも定性分析の統合もない
- **既存ツールのどれも**、理論株価算出＋透明な計算過程＋定性分析＋動的ポートフォリオ管理を無料で統合的に提供していない

### 提案するソリューション

以下を実現するWebアプリケーション。二段構造の意思決定フレームワークを提供する：

**第一段階：銘柄選定（どの会社に投資するか）**

決算指標はあくまで事業の結果であり、過去を示すに過ぎない。未来を予測し、長期投資に値する企業かを判断するには定性分析が不可欠である。銘柄選定は以下のサブステップで進む：

1. **スクリーニング** — 粗いフィルタリングで候補を絞り込む
2. **ライト定性分析** — 事業領域は何か、どんな会社か、をざっくり把握する
3. **定量分析** — 財務データを入力し、理論株価を算出。数値的に基準を満たすか評価する
4. **ディープ定性分析** — 競争優位性の源泉はどこか、それは持続可能か、経営者は言行一致しているか。本格的に調査する
5. **ロースター決定** — 定量・定性の総合評価に基づき、動的な投資ロースター（スタメン／スーパーサブ／ベンチ／候補生／分析済み落第）に分類する

**第二段階：売買タイミング（いつ売買するか）**
- 理論株価と市場価格のギャップに基づいて「今の価格は割安／割高／適正」の判断材料を提示
- 最終的な判断は常に投資家自身が行う

**透明性の原則（全体を貫く設計思想）：**
1. **計算ロジックの完全開示** — すべての数式とその理論的根拠を閲覧可能
2. **データ判定の透明性** — 「有利子負債をこう定義し、この会社のこの勘定科目を有利子負債として判定した」を明示
3. **パラメータのユーザー制御** — 重要な前提値（成長率、割引率、将来利益予測等）をユーザーが調整可能。ツール標準値はデフォルトとして提供
4. **教育コンテンツの統合**（OSS公開フェーズ） — 「なぜこの計算が有効か」を株価決定理論に基づいて解説

**具体的な機能：**
1. **財務データ収集の段階的自動化** — EDINET等から取得。完全自動が困難な項目はAIが候補値を提示しユーザーが確認・修正する半自動方式。判定過程を透明に記録
2. **理論株価の算出** — 山口揚平氏の手法をベースとした評価理論に基づき計算。計算過程は完全開示
3. **AIによる定性分析の支援** — IR資料から事実を整理（経営者の発言と実績の一致度、競争優位性の持続性等）。スコアリングではなく事実の提示に徹し、判断は投資家に委ねる
4. **動的な投資ロースター管理** — 最新の財務データと定性評価に基づいて銘柄を組み替え
5. **分析履歴の保持** — 投資家の考え方の変遷、過去の判断、各企業に対する根拠を時系列で蓄積

### 主要な差別化ポイント

- **透明性が最大の差別化**: 計算の定義・過程・判定理由をすべて開示する。既存ツールが結果だけ見せるのに対し、「なぜその数字になったか」を理解できる
- **理論の民主化**: 企業価値評価の基本理論を、誰でも無料で、中身を理解しながら使える。怪しい投資商材の真逆
- **信念＋客観性の両立**: 「こういう会社がいい会社だ」という投資家個人の価値基準と、厳密な財務分析を独自に統合
- **無料かつオープンソース**: 投資リターンを食い潰すペイウォールなし。計算ロジックの完全な透明性
- **定性＋定量の統合**: AIによる事実整理（モート分析・経営者の信頼性追跡）と、伝統的な財務指標を一体化
- **日本市場フォーカス＋グローバル展望**: EDINET連携で日本株を初期ターゲットとしつつ、国際展開を見据えたアーキテクチャ

### MVPロードマップ

1. **理論株価計算エンジン** — 既存スプレッドシートの計算ロジック移植、パラメータ調整可能
2. **データ入力の効率化** — EDINET自動取得＋半自動確認、透明性のある判定ログ
3. **ロースター管理** — スタメン〜分析済み落第の動的管理、銘柄間比較
4. **定性分析（AI支援）** — IR資料ベースの事実整理、経営者の言行追跡
5. **教育コンテンツ / OSS拡張** — 理論解説、ペルソナB（新規ユーザー）向け導入ガイド

## ターゲットユーザー

### プライマリユーザー

**ペルソナA：「理論派の個人投資家」（MVP対象）**

> **藤田（30代・会社員）** — 投資歴5年程度。最初は知っている企業の株を適当に買ってヒヤヒヤしていたが、書籍で企業価値評価の理論を学び、自分のスプレッドシートで理論株価を計算するようになった。今はそれなりに儲かっているが、「もっといい投資ができるはず」と感じている。

- **普段の行動**: 平時はスクリーニングツール（株探等）で粗くフィルタリングし、良さそうな企業の事業領域をざっくり調べた上で決算資料から財務データをスプレッドシートに手入力して詳細分析する
- **決算シーズン**: ひたすらデータ入力に追われる。保有株と候補銘柄の売買ラインをここで決定する。面倒すぎて後回しになりがちで、抜け漏れも多い
- **課題**: データ入力の時間が膨大で、本来やりたい分析と判断に集中できない。定性分析が手薄で、数値だけでは「本当にいい会社か」の確信が持てない
- **成功の姿**: 決算が出たらデータが素早く揃い、理論と個人の信念にもとづいた企業のフィルタリング、理論に基づいた売買判断を自信を持って行っている状態

### セカンダリユーザー

**ペルソナB：「不安を抱える投資家」（OSS公開後の主要対象）**

> **田中（30〜40代・投資に興味はあるが自信がない）** — 新NISAをきっかけに投資を始めた、あるいは数年やっているが、常に不安を感じている。自分の判断に自信が持てず、SNSの情報や周囲の意見に流されやすい。怪しい投資商材にも惹かれがちだが、本心では「ちゃんとした根拠で投資したい」と思っている。

- **普段の行動**: 証券会社のアプリで株価を頻繁にチェック。下がると不安になり、上がると「もっと買えばよかった」と後悔する。判断基準が曖昧なため、感情に振り回される
- **課題**: 何を根拠に売買すればいいかわからない。理論があることは知っているが、どう実践すればいいかわからない
- **成功の姿**: 理論株価の計算方法を学び、自分で選定した銘柄の根拠を説明でき、一時的な株価変動に動じず中長期で保有する自信を持てる状態。「自分で選んだ銘柄で利益が出た」という成功体験を積む

**ペルソナC：「無根拠な自信を持つ投資家」（優先度：低）**

> 投資経験はあるが理論を学んでおらず、勘と経験則で売買している。現状うまくいっているため理論の必要性を感じていない。本ツールのターゲットではあるが、サービスの必要性を自覚しにくいため、自然流入は期待しない。

**OSS公開の動機**: 開発者としてOSS活動に挑戦したいという個人的な動機も含む。ペルソナBへのリーチ戦略（ブログ、技術記事等の導線）はOSS公開フェーズで別途検討する。

### 対象外ユーザー

- **デイトレーダー・短期売買志向の投資家**: 本ツールは中長期の企業価値分析に特化。日次〜月次の価格変動を利用した売買スタイルには対応しない
- **株主優待目的の投資家**: 中長期の資産増加（株価上昇＋配当）を目的としたツールであり、優待リターンの分析は範囲外
- **「相場の天才」自認タイプ**: 短期的な株価の上下を見極めて売買するスタイル。理論に基づく企業価値評価とはアプローチが根本的に異なる

### ユーザージャーニー

**ペルソナA（MVP）の典型的なジャーニー：**

| フェーズ | 行動 | ツールの役割 |
|---------|------|-------------|
| **発見** | 決算シーズンの手入力に疲弊し、「もっといい方法ないか」と検索 | GitHub/技術ブログで発見 |
| **オンボーディング** | 今期の決算データから使い始める。計算ロジックが透明なので「自分のやり方と同じだ」と確認できる ※過去データのインポートはオプション機能として将来対応 | 計算ロジック閲覧、初期データ投入 |
| **コア利用（決算期）** | 決算が出たらデータが自動/半自動で取得される。理論株価が更新され、ロースターを見直す | データ取得、理論株価算出、ロースター管理 |
| **コア利用（平時）** | 新しい候補銘柄を探索。ライト定性（どんな会社か）→ 定量分析 → ディープ定性（競争優位性）の順で評価 | 財務分析、定性分析AI |
| **"あ、これだ"の瞬間** | 理論株価と市場価格のギャップを見て、定量・定性の根拠を持って「今が買い時だ」と判断できた時 | 判断材料の統合ビュー |
| **長期定着** | 分析履歴が蓄積され、過去の判断を振り返れる。自分の投資哲学の成長記録になる | 分析履歴、ロースター変遷 |

※MVP後の拡張として、スクリーニング→詳細分析の一気通貫フローを検討

## MVPスコープ

### コア機能

**Phase 1: 理論株価計算エンジン + 最低限のWebUI**
- 銘柄を選択して財務データを手動入力
- 以下の指標を自動算出：
  - 理論株価（山口揚平氏の手法ベース）
  - ROE / ROA / ROIC
  - 自己資本比率
  - 営業CF / 投資CF / FCF
  - PER / PBR
- 選択した銘柄の理論株価・各指標を一覧表示
- 計算ロジックの閲覧機能（透明性の原則）
- 重要パラメータ（成長率、割引率等）のユーザー調整

**Phase 2: データ入力の効率化**
- EDINET等からの財務データ自動取得（主要項目）
- 自動判定が困難な項目は半自動（候補値提示 → ユーザー確認）
- データ判定ログの記録・表示（「この勘定科目をこう判定した」の透明性）

### 将来フェーズの概要

**Phase 3: ロースター管理＋スクリーニング**
- 銘柄をスタメン／スーパーサブ／ベンチ／候補生／分析済み落第に分類・管理
- 分類変更の履歴と理由を記録（なぜ昇格/降格したか）
- 銘柄間の比較ビュー（同セクター内での優劣など）
- 簡易スクリーニング機能（現状は株探等の外部ツールで代替）
- 将来的にスクリーニング→詳細分析の一気通貫フローを目指す

**Phase 4: 定性分析（AI支援）**
- **ライト定性**: 事業概要・セクター・主要事業の自動取得。銘柄追加時に「どんな会社か」をざっくり表示
- **ディープ定性**: IR資料（決算説明資料、中期経営計画等）から事実を整理
  - 経営者の過去の発言 vs 実績の追跡（言行一致度）
  - 競争優位性の源泉の特定（ブランド、ネットワーク効果、スイッチングコスト、規模の経済等）
  - その優位性が今後も持続可能かの材料提示
  - 海外展開の状況（日本市場のシュリンクリスクへの対応）
- AIはスコアリングせず事実の提示に徹する。判断は投資家が行う
- データソース: EDINET、企業IRページ、決算説明会資料

**Phase 5: 教育コンテンツ / OSS・公開準備**
- 「なぜこの計算式で理論株価が出るのか」を株価決定理論に基づいて解説
- 定量分析 = バックミラー（過去の事実）、定性分析 = フロントガラス（未来の見通し）というフレーミング
- ペルソナB（不安を抱える投資家）向けの段階的な導入ガイド
- OSS公開 or 課金アプリとしてのリリース判断
- ペルソナBへのリーチ戦略（ブログ、技術記事等の導線）の検討

**オプション（時期未定）**
- 過去データのインポート（CSV/スプシからの移行ツール）
- モバイル対応（レスポンシブUI）
- 国際市場対応（EDINET以外の開示APIへの対応）

### MVP成功基準

- 既存スプシと同等の理論株価計算結果が出力できる
- 財務データの（半）自動取得により、手入力の負担が大幅に減る
- 自分自身がスプシの代わりに日常使用している

### 技術スタック（暫定）

- **フロントエンド / バックエンド**: Next.js (App Router) — TypeScript
- **データベース**: PostgreSQL (Supabase 無料枠)
- **デプロイ**: Vercel (無料枠)
- **EDINET XBRL解析**: Python スクリプト（Phase 2で導入）
- **月額運用コスト**: ¥0（無料枠の範囲内）
